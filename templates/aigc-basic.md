# 模板：AIGC 实战入门课（aigc-basic）

## 定位

面向零基础学员的 AIGC 实操入门口播课。结构：先给成品愿景 → 讲 AI 链路 → 讲边界/案例 → 给一个真实任务 → demo 展示 → 预告下一节。

## 风格参数

- 主题：暖橙活力几何（见 `../assets/design-style.json`）
- 字幕：`../assets/captions-style.md`
- 术语贴片：竖版左置（left 48 / top 300），半透明 0.78
- 章节卡：开场=AI 工作链路图；中段=AI 大脑图；结尾=普通人生成场景图
- 分段进度条：4 段，按本节内容章节定 marks/labels；放最顶层轨道，整片时长

## 术语表（贴片文案）

| 英文 | 中文解释 | 类别 |
|---|---|---|
| PROMPT | 提示词：用自然语言向 AI 描述你想要的 | 核心概念 |
| LLM | 大语言模型：AI 的“大脑”，负责理解和生成语言 | 核心概念 |
| AGENT | 智能体：能调用工具、操作文件、执行任务的 AI | 核心概念 |
| SKILL / MCP TOOLS / API / 工作流 | 技能包 · 工具 · 服务 · 串联成产品（链路贴片） | 链路 |
| HALLUCINATION | AI 幻觉：一本正经胡说八道，结果要检查 | 风险提醒 |
| HARNESS | AI 编排层：给 Agent 操作文件和软件的权限 | 底层机制 |
| VIBE CODING | 让 AI 写代码做网页，专业术语叫 Vibe Coding | 实战技能 |
| 下一节 · LLM | 什么是大语言模型？我们下节课见 | 课程预告 |

## 章节卡文案

- 开场：标题“第 X 节 · 本节主题”，副标题“<课程名>”
- 中段：按内容取，如“这门课，围绕一个真实项目展开” / “把 AIGC 入门最重要的能力串起来”
- 结尾：标题“下一节 · <下节主题>？”，副标题“第 X+1 节 · <小标题>”

## 生图方向

概念插图按 `../assets/image-prompts.md` 三张基准确认后再扩展；风格必须与模板主题一致。

## 剪辑注意

- 该课程常见：同一链路讲两遍（保留完整版）、demo 重复播放（保留第一遍）、数字人失败重录（整段删）
- 常见 ASR 错词：skill→scale、Prompt→Pront、vibe coding→web coding、Whale→Well、名字误识（豆包/豆根→豆哥）
